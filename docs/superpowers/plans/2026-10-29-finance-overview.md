# 财务总览实施计划

目标：以现有 ezBookkeeping 账本为底座，交付手机和电脑可用的总览、收支、资产、投资页面，指标来自实际接口，未知数据明确标记。

架构：独立 React/TypeScript 前端，开发代理访问本机现有账本，不修改上游配置和数据库。金额以整数分处理；统计采用北京时间；当前资产与所选月份收支明确分开。

视觉方向：安静的财务工作台。白色主面、墨色数字、绿色收支结余、红色支出、蓝色投资；横向资产构成条作为主要数据图形，紧凑分区，无装饰性大屏。

## 实施与验证

- [x] 建立 `package.json`、`vite.config.ts`、`src/api.ts`、`src/finance.ts`：会话登录、游标分页、金额与月份计算。以 `src/finance.test.ts` 验证跨月、转账排除、多币种与整数金额。
- [x] 建立 `src/App.tsx`、`src/styles.css`、`src/main.tsx`：四页、账单筛选与详情、账户下钻、真实记账提交、导入入口；首次使用可主动创建独立演示账本。
- [x] `npm test`、`npm run build`；浏览器检查电脑与手机尺寸、导航、筛选、记账、重新加载、错误反馈、溢出。
- [x] 更新 README 的启动方式、交付范围和限制，保留原版账本入口。

边界：不接真实银行或券商，不模拟通知采集和证券收益；不将账本刷新时间描述成银行同步时间；不以不完整数据计算资产增长或同期涨幅。

验收结果：6 项计算及分页测试、生产构建、9 项浏览器流程通过。手机布局在 412px 与 360px 下四页均无横向溢出；无未捕获的浏览器错误。模拟服务故障后保留并标注旧数据，重试可恢复。真实提交 ¥0.29 支出后净资产和收支统计一致更新。截图与验证记录位于忽略目录 `.local/`。

# 一木界面与记账流程对齐

**授权：**用户要求尽量一比一，包括 UI，并于 2026-10-31 回复「ok」。以现有一木 6.7.0 布局、颜色和演示视频为证据；未有动态证据的部分不宣称像素级还原。

**目标：**安卓优先，将现有长表单改成分类区、底部输入区和固定数字键盘的记账界面；首页、统计、账户及设置沿用相同视觉语言，网页响应式适配。

**架构：**保留 Kotlin Compose / React、现有账单领域逻辑和持久化同步。独立实现界面，不复制第三方代码或图片。无数据库、鉴权、域名及生产配置变更。

## 参照依据

- `activity_add_bill.xml`：50dp 顶栏，34dp 收支切换；中央分类分页；底部备注与金额同行；日期、账户、属性横排；220dp 数字键盘。
- `colors.xml`：背景 #f6f6f6；主色 #48ab93；支出 #fb5655；正文黑色、次级 #666666。
- `fragment_home.xml`、`activity_main.xml`、`item_bill_main_detail_list.xml`：核对首页层次与账单行。
- 原报告属于静态分析，不证明首次启动默认账户、动态主题和所有支付弹窗行为。

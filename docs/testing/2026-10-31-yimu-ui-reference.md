# 一木 UI 对照依据

## 用户目标

尽量按一木记账还原界面及交互，安卓优先、电脑适配。沿用本项目账单与同步能力。本文件区分直接观察、静态布局和本项目适配，不把提炼文档中的建议冒充一木真实行为。

## 本项目明确保留的边界

- 三个主入口仍为账单、统计、我的；不重新加入股市功能。
- 账户与余额是不同概念：账户可以没有余额基线；不能自动填零。
- 账户创建为用户显式操作，录入草稿不因打开创建表单而丢失。
- 未确认账户的自动采集结果不因 UI 调整而变为已入账。
- 本次没有修改数据库结构，也不重新执行已发布 SQL。
- 未经截图与真机核对的部分不标记为完整一比一还原。

### 与一木仍有差异的部分

- 数字键盘暂仅支持小数输入与删除，没有计算器四则运算和「再记」快捷连续录入。
- 使用本项目自己的图标实现；未复制一木图标文件，图形不会完全相同。
- 只保留已实现功能，不放置没有处理逻辑的悬浮窗、附件等开关。
- 尚无用户提供的当前一木真机逐屏录屏；包内教学视频可能较早，不能称为所有页面的像素级验收。
